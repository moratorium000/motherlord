### 심화 과정 (벤치 엔지니어)

기본 과정 M00–M17 을 마친 사람이 **완성된 보드를 받아 살려내고, 재고, 고쳐서,
양산으로 넘기기까지** 하는 데 필요한 것들입니다. **집적회로(IC) 내부는 다루지
않습니다** — 벤치 엔지니어의 손이 닿는 범위, 즉 커넥터·보드·모듈·시스템까지입니다.

이론 62 h + 실습 94 h = **156 h** · 심화 캡스톤 40 h. 설계서 §3에 **기본 과정과의
개념 소유권 경계**를 표로 두어, 심화 모듈이 M00–M17이 이미 소유한 개념을 다시
정의하지 않도록 했습니다.

**B01·B02 를 썼습니다(26 h).** B01 은 워밍업 드리프트가 만드는 **0.250 dB 짜리
가짜 개선**과, 재연결 산포 σ = 0.03 dB 에서 0.03 dB 를 주장하려면 **한쪽당 8번**을
재야 한다는 계산으로 "한 번 재고 판단하지 않는다"를 세웁니다. B02 는 스코프
대역폭이 신호의 **5배여야 상승시간 오차가 2 %** 라는 것, 100 mm 접지 리드가
**178 MHz 에서 70 % 오버슈트**를 만든다는 것, 그리고 배스터브 외삽을 다룹니다.

배스터브 곡선에서 읽은 총 지터가 닫힌 식 TJ = DJ + 2·Q·RJ 와 **네 오류율에서
0.02 ps 이내로 맞는지** 대조합니다. 접지 리드 모형은 계측사가 든 사례(1.5 pF
능동 프로브 · 3~6인치 리드 → 350~550 MHz)를 **531 / 375 MHz 로 재현**해 검증했습니다.

**B03 은 픽스처를 다룹니다(14 h).** 차동 쌍의 길이가 **0.83 mm 어긋나면 5 GHz
에서 −22 dB** 가 공통 모드로 새고, 그 관계가 |Sdc21| = |sin(π f Δτ)| 라는
닫힌 식으로 떨어집니다. 픽스처 제거는 `scikit-rf` 에 들어 있는 **IEEE 370
표준 구현**을 그대로 돌려, 임피던스 보정 유무에 따라 무너지는 곳이 다르다는
것을 보입니다 — 보정 없는 쪽은 대역 안에서 0.005 dB 인데 **맨 위 5 %에서
3.72 dB** 로 터지고, 보정판은 끝은 멀쩡한 대신 전 구간에 0.36 dB 가 남습니다.
결론은 "어느 쪽이 낫다"가 아니라 **쓸 대역보다 넓게 재고 가장자리를 버려라**
입니다.

**B04 는 대신호입니다(16 h).** 2-tone 이 통과해도 실제 파형에서 떨어지는 이유를
따라갑니다. 압축이 겨우 1 dB 인 지점에서 **위상은 이미 14.7° 돌아 있고**(벡터
오차로는 진폭 쪽 11 %보다 큰 25.6 %), 같은 소자·같은 전력인데 **톤 간격만 바꾸면
상·하 IM3 가 2.9 dB 갈라집니다.** 그 봉우리가 바이어스망 공진(310 kHz) 자리에서
나온다는 것까지 계산으로 보입니다. 열은 펄스로 떼어 냅니다 — CW 100 °C 대 10 µs·
듀티 1 % 의 9.5 °C, 이득으로 **1.09 dB** 차이입니다. NPR 절은 "왜곡만 보면 59 dB
인데 **화면에는 42 dB 가 최대**"라는 그림으로 측정 천장을 먼저 재는 습관을
세웁니다. 로드풀은 300 W 소자가 원하는 |Γ| 0.87 을 **사이 손실 0.5 dB 만 있어도**
수동 튜너가 못 만든다는 것을, DPD 는 무기억 보정이 남기는 **8.1 dB 의 상·하
비대칭**이 메모리의 지문이라는 것을 보입니다.

**B05·B06 은 잡음과 위상잡음의 심화입니다(28 h).** B05 는 "데이터시트 0.65 dB
인데 왜 우리 보드는 다른가"를 네 개의 잡음 파라미터로 풉니다. 같은 소자를 50 Ω
소스로 재면 **1.00 dB** 가 나오고, 잡음 최소점 Γopt 와 이득 최대점 Γms 는
**0.755 만큼** 떨어져 있습니다. 그 사이에서 **잡음 0.10 dB 를 내주면 이득
2.01 dB 를 얻습니다** — Γopt 에 정확히 앉는 것이 대개 손해라는 뜻입니다.
소스풀에서는 계산이 실무 규칙 하나를 만들어 냈습니다. 점을 **한 반지름 위에만**
찍으면 설계 행렬의 조건수가 1.8×10¹⁶ 이 되어, **측정에 잡음이 하나도 없어도**
Fmin 이 0.380 dB 틀립니다. 저 NF 측정의 합성 불확도는 0.291 dB — **읽은 값
0.6 dB 의 49 %** 입니다.

B06 은 요즘 장비의 교차상관 방식을 다룹니다. 바닥은 **10배 평균에 5 dB** 만
내려가고(20 dB 를 벌려면 10 000회), 전력 분배기의 열잡음이 두 채널에 **반대
위상**으로 들어와 **교차 스펙트럼을 붕괴**시킵니다 — 참값이 분배기 열잡음보다
0.5 dB 위면 **9.6 dB 낮게** 찍히고, 평균을 늘려도 안 없어집니다. 이 오차는
언제나 좋은 쪽으로만 나므로 **좋은 값이 나왔을 때 의심해야 합니다.** 지터
쪽에서는 같은 곡선을 10 Hz 부터 적분하면 90.8 fs, 12 kHz 부터 적분하면
11.3 fs 가 나옵니다 — **적분 구간 없는 지터 값은 숫자가 아닙니다.**

**B07·B08 은 보드가 나온 뒤의 이야기입니다(26 h).** B07 은 시험소 성적서의
한 줄에서 보드 위 한 점까지 내려가는 절차입니다. 보드를 보기 전에 사다리꼴
클럭의 포락선으로 **볼 주파수 목록**을 만들고(꺾임은 1/(π·d·T) 와 1/(π·t_r)),
근접장 프로브로 자리를 짚습니다 — 8 mm 떨어진 도체 둘을 2 mm 고리는 **4.2 dB
골**로 가르지만 20 mm 고리는 0.2 dB 밖에 못 가릅니다. 케이블 쪽은 계산이 더
날카롭습니다. **1 m 케이블에 8 µA** 만 공통모드로 흘러도 30 MHz 에서 한도
40 dBµV/m 에 닿습니다 — 신호 전류의 1만분의 1 입니다. 대책은 주파수를 탑니다:
100 MHz 용 페라이트가 공진에서 9.9 dB 를 주고 1 GHz 에서 1.7 dB 로 떨어지며,
차폐 효과를 정하는 것은 금속 두께가 아니라 **구멍의 길이**입니다.

B08 은 전원을 넣는 순간부터 값을 적을 때까지입니다. 빈 벌크 커패시터가 만드는
돌입 첨두가 **정상 전류의 347배**이고, 그때 흔들린 전압이 게이트 바이어스를
무너뜨려 소자를 죽입니다. 효율은 정의가 값을 정합니다 — **같은 측정이 58.7 %
와 49.3 %** 로 적힙니다. 그래서 에너지 수지(Pdc + Pin = Pout + 손실)를 닫아
보는 절차를 넣었습니다. 그리고 대기 시간: 다이는 수십 ms 에 데워지지만
히트싱크는 분 단위라, **±0.05 dB 안에서 판정하려면 10.3 분**을 기다려야
합니다.

**B09·B10 은 완성품에서만 드러나는 문제들입니다(26 h).** B09 는 도선을 뗀
뒤의 측정입니다. TRP(총방사전력)는 구면 적분이고, 적분은 표본 간격을 탑니다 —
30° 격자(60점)는 등방 패턴을 0.10 dB 안에 맞히지만 16 dBi 지향성 안테나에서는
**5.09 dB 를 놓칩니다.** 그런데 격자를 촘촘히 해도 소용없는 경우가 있습니다.
불확도 예산을 세워 보면 합성 0.858 dB(k=2 로 ±1.72 dB) 중 가장 큰 항이
**기준 안테나 이득 교정 0.45 dB** 이고 표본 간격 항은 그보다 작습니다. 시간도
설계 변수입니다 — 같은 30° 격자에서 TRP 는 3.9 분, TIS(총등방감도)는
**124 분(32배)** 이라, 규격이 TIS 격자를 더 성기게 두는 이유가 여기 있습니다.
그리고 측정 케이블은 관찰자가 아니라 **안테나의 일부**여서, 위치만 바꿔도
TRP 가 3.11 dB 폭으로 움직입니다.

B10 은 "Wi-Fi 를 켜면 감도가 떨어진다" 를 추적하는 절차입니다. 디센스는
Δ = 10log₁₀(1 + I/N) 하나로 정리되는데, 이 식이 무서운 이유는 **잡음 바닥보다
5.9 dB 낮은 간섭도 1 dB 를 먹는다**는 데 있습니다. 각각 1 dB 씩인 다섯 개
부시스템은 5 dB 가 아니라 **5.04 dB** 로 쌓이므로, 하나씩 켜서 재는 절차가
성립합니다. 범인은 대개 클럭 하모닉입니다 — 2.2 MHz DC-DC 스위처는 Wi-Fi
대역을 38번, GNSS L1 을 **716차 하모닉**으로 한 번 칩니다. 대책 쪽에서는
SSC(스프레드 스펙트럼 클럭)를 두 번 의심해야 합니다. 첨두 저감은 RBW 를
따라 커 보이지만(488 kHz 에서 6.0 dB, 1.9 kHz 에서 17.7 dB) **변조 주파수보다
좁아지면 거기서 멈추고**, 대역 총전력은 **0.000 dB** 그대로입니다 — 계기의
눈금을 낮췄을 뿐 수신기가 받는 에너지는 그대로입니다.

**B11·B12 는 숫자를 믿게 만드는 층입니다(22 h).** B11 은 "제가 재면 통과, 옆자리가
재면 탈락" 을 분산분석으로 가릅니다. 산포를 반복성·재현성·부품 산포로 쪼개면 좋은
게이지는 부품 산포가 **99 %** 를 차지하고, 나쁜 게이지는 측정계가 32 % 를 먹습니다.
여기서 초심자가 놀라는 일이 하나 나옵니다 — 공정을 개선해 부품 산포를 0.300 →
0.100 dB 로 좁혔더니 **같은 게이지가 9.6 % 에서 28.4 % 로 불합격이 됐습니다.**
계산 오류가 아니라 정의의 결과입니다. 판정 기준도 서로 어긋납니다: AIAG 가
요구하는 두 기준 중 **ndc ≥ 5 의 경계는 %GRR 27.1 %** 라, %GRR 이 정확히 30 % 인
게이지는 "조건부 합격이면서 ndc 불합격" 입니다. 장비를 맞댈 때는 최소제곱을 쓰면
안 됩니다 — 가로축에도 오차가 있어 기울기가 **참값 1.000 을 0.870 으로 깎고**,
축을 바꾸면 답이 달라집니다(0.870 대 1.080). 데밍 회귀는 1.019 로 참값에 붙고 축을
바꿔도 같습니다.

B12 는 그 측정을 라인으로 옮깁니다. 같은 열 항목이 벤치에서는 46 분, ATE 에서는
**21.0 초** 입니다. 사이트를 늘려도 계측기를 나눠 쓰면 소용없습니다 — 공유 비율이
20 % 밖에 안 되는데 8 사이트에서 **1321 대 562 UPH** 로 갈립니다. 항목을 뺄 때는
상관만으로 결정하지 않고 **빠뜨림 ppm** 을 계산하는데, 열 항목 중 500 ppm 선을
넘지 못한 것은 물리적으로 묶인 한 쌍(수신 감도·잡음지수, 상관 0.98)뿐이었고
**둘 다 빼면 3배로 샜습니다.** 가드밴드에는 가격표가 붙습니다 — 빠뜨림을 6,385 →
99 ppm 으로 줄이는 값이 헛수고 **9배**입니다. 그리고 재시험: 같은 3회 측정인데
"붙을 때까지 다시 재기" 는 빠뜨림을 6,138 → 12,904 ppm 으로 **늘리고**, "중앙값으로
판정" 은 4,029 ppm 으로 **줄입니다.** 정책이 방향을 정합니다.

M05가 "교정은 M14가 소유한다"며 **일부러 교정 없이 측정하게 해 둔 빚**을 M14에서 갚습니다. 오차항을 넣은 가짜 VNA로, 교정 전에는 진짜 노치(2.40 GHz, −44.4 dB)를 21.7 dB 얕게 읽고 **없는 노치를 2.70 GHz에서 보여 준다**는 것을 계산으로 보입니다. 1-포트 교정은 손으로 한 번, `scikit-rf`로 한 번 **독립 구현해 대조**했습니다.

M15의 중심은 **"측정계 자신을 먼저 잰다"** 입니다. 화면의 IM3가 DUT 것인지 분석기 것인지는 전력을 바꿔서는 구분되지 않고(둘 다 기울기 3이라 평행선), **분석기 앞 감쇠기를 옮겨야** 갈립니다 — DUT 몫은 1:1, 분석기 몫은 3:1로 내려갑니다.

M14·M15가 **믿을 수 있는 숫자**를 만들었다면, M16은 그 숫자로 **판정하고 고칩니다.**

가드밴딩은 해석식(이변량 정규분포)과 **몬테카를로 400만 회**로 각각 계산해 0.05 %p 안에서 대조했습니다. 결과가 불편합니다 — 확장불확도만큼 가드밴드를 두면 오합격은 2.21 % → 0.06 %로 떨어지지만 **양품의 52 %를 버립니다.** 이것은 계산 실수가 아니라 **설계 마진이 얇다는 사실이 드러난 것**이며, 모듈은 이 결론을 감추지 않습니다.

튜닝 절에는 집필 중 실제로 낸 실수를 그대로 남겼습니다. 실수부를 50 Ω으로 만드는 병렬 소자 값은 **두 개**가 나오는데, 한쪽을 고르면 다음 단계가 **−2.30 nH**가 됩니다. 계산은 맞았고 부품이 없었습니다.

L16-d는 **가짜 VNA**를 물고 있어 장비 없이 돌아갑니다. 성긴 소인(11점)이 노치를 0.31 dB 얕게, 50 MHz 옆에서 보는 것을 학습자가 직접 확인합니다.

**주어진 요구사항에는 모순 세 건이 일부러 들어 있습니다.** 찾아내는 것이 첫 과제입니다.

감도 −95 dBm @ 20 MHz에 NF ≤ 4 dB는 SNR 2 dB로 충분해야 한다는 뜻인데, 이 파형은 5 dB를 요구합니다 — **3 dB 모자랍니다.** 출력 +20 dBm에 안테나 2 dBi면 EIRP 22 dBm으로 **규제 상한을 2 dB 넘습니다.** 그리고 잡음지수와 선형성은 **어느 한 이득 배분으로도 동시에 만족되지 않습니다**(고이득 NF 3.86 dB/IIP3 −22.3 dBm, 저이득 NF 18.1 dB/IIP3 +1.9 dBm) — AGC로 모드를 나누고 요구서에 어느 모드인지 명시해야 합니다.

세 모순은 성격이 다르고 대응도 다릅니다. 하나는 협의, 하나는 법이라 협의 불가, 하나는 설계로 풀립니다.

계산 도구도 함께 둡니다.

```bash
python3 scripts/capstone_check.py          # 자기 예산을 넣고 합·부를 본다
python3 scripts/capstone_check.py --self   # 도구 자체의 검산 26항목
```

도구를 만들며 확인한 것 하나: **2.4 GHz 대역에서는 83.5 MHz 미만의 어떤 클럭도 대역 내 하모닉을 피할 수 없습니다.** 하모닉 간격이 곧 클럭 주파수인데 그것이 대역폭보다 좁기 때문입니다. 그래서 답은 주파수 계획이 아니라 **격리 예산 77 dB**이고, 그 숫자가 P2의 보드 설계 목표가 됩니다.

**그림 번호가 읽는 순서와 어긋나 있었습니다.** M02는 캡션이 1, 3, 4, 6, 2, 7 순으로

실제로 해 보는 사람이 시간에 쫓기므로, **주차표에 분량 열을 붙여 어긋남을 드러내고**

| **책등** | **28.7 mm** (미색모조 80 g/m² 기준) |
| 본문 | 흑백 1도 양면, 안쪽 30 mm / 바깥 20 mm |
| 표지 | 4도 단면, 아트지 250 g/m² + 무광 라미네이팅 |

**책등 두께는 손으로 적지 않습니다.** 쪽수를 실제 PDF 에서 읽고 종이 평량과
부피에서 계산합니다. 이 값 하나가 표지 전개도의 폭과 발주서의 표를 함께
움직이므로, 종이가 바뀌면 `spec.py` 의 한 줄만 고치면 됩니다.

```bash
python3 scripts/print/spec.py        # 규격 계산 + 검산 6항목
python3 scripts/print/gen_cover.py   # 표지 (잉크량·선 굵기 자동 점검)
python3 scripts/print/make_body.py   # 본문 (접지·쪽수·발주서 대조 9항목)
```

접지 여백은 **글자 좌표를 실제로 재서** 확인합니다 — 홀수 쪽이 +14.2 pt,
짝수 쪽이 −14.2 pt 움직였는지 봅니다. 5 mm 는 눈으로 봐서는 알 수 없습니다.

앞표지의 스미스 차트는 이미지가 아니라 **등저항 원과 등리액턴스 호를 계산해
그린 벡터**입니다. 인쇄 크기가 바뀌어도 깨지지 않습니다.

> 560쪽 무선제본은 가능한 두께지만 얇지 않습니다. 인쇄소가 어렵다고 하면
> **상·하권 분책**(Part 0–IV / Part V–VI + 부록, 각 약 280쪽)이 대안이며
> 발주서 §6 에 적어 뒀습니다.
