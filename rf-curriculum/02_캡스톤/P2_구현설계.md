## P2.0 이 단계에서 하는 일

P1이 만든 것은 **스펙**입니다: "이득 22 dB, 잡음지수 0.9 dB 이하, IIP3 −10 dBm 이상인 LNA가 필요하다."

P2가 하는 일은 그 스펙을 **살 수 있는 부품**과 **만들 수 있는 보드**로 바꾸는 것입니다.

> ⚠️ **P2에서 예산이 깨집니다.** 스펙대로인 부품은 없습니다. 어떤 것은 잡음지수가 좋은 대신 IIP3가 나쁘고, 어떤 것은 다 좋은데 단종 예정입니다.
>
> **부품을 고를 때마다 예산표로 돌아가 다시 돌리십시오.** P1의 도구가 여기서 계속 쓰입니다.

## P2.1 산출물 ⑤ — 부품 선정 근거서

### 부품 하나마다 채우는 표

| 열 | 적는 것 | 왜 |
|---|---|---|
| **필요 스펙** | P1의 예산표가 요구한 값 | 출발점 |
| 후보 | 부품번호 2~3개 | 하나만 보면 비교가 안 된다 |
| **데이터시트 값** | 해당 파라미터 값 | |
| **Typ인가 Min/Max인가** | 반드시 구분 | **Typ은 보증이 아니다** (→ [M16 §2](../01_모듈/M16_DUT검증과튜닝과자동화.md)) |
| **조건 줄** | 전압·전류·온도·임피던스를 그대로 인용 | 조건이 다르면 숫자도 다르다 (→ [M16 §1](../01_모듈/M16_DUT검증과튜닝과자동화.md)) |
| 온도 범위 | 보증 온도. 없으면 "없음" | 25 °C만 보증한 값이 흔하다 |
| 마진 | 필요 스펙 − 보증값 | 못 적으면 그 줄은 안 끝났다 |
| 판정 | OK / 확인 필요 / 직접 시험 | |
| **선택 이유** | 왜 이것을 골랐는가 | 채점 대상 |
| 공급 | 재고, 단종 여부, 2차 공급처 | 실무에서 자주 무너지는 곳 |

> 📌 **이 표는 [M16 §3](../01_모듈/M16_DUT검증과튜닝과자동화.md)의 스펙 매핑표와 같은 것입니다.** M16에서 익힌 양식을 그대로 씁니다.

### 반드시 마주칠 문제

**① 잡음지수가 Typ만 적혀 있다**

LNA 데이터시트에서 가장 흔한 일입니다.

| 대응 | 언제 |
|---|---|
| 제조사에 보증값 요청 | 물량이 있을 때 |
| **직접 재서 분포를 만든다** | 시료를 구할 수 있을 때 (→ P3) |
| **Typ + 0.5~1 dB로 가정** | 위 둘이 안 될 때. **근거를 기록** |

> ⚠️ **Typ 값을 그대로 예산에 넣으면 생산품의 절반이 예산을 벗어납니다.** P1에서 마진을 1 dB 남겨 둔 이유가 여기 있습니다.

**② 부품의 기생 성분**

정합 회로의 인덕터·커패시터는 [M06](../01_모듈/M06_수동소자와공진.md)의 자기공진(SRF)을 확인해야 합니다.

| 확인 | 기준 |
|---|---|
| SRF | **동작 주파수의 최소 3배** 이상 |
| Q | 정합 회로 손실에 직결 |
| 크기 | 0402가 0603보다 SRF가 높다 |
| 직류 정격 | PA 바이어스 경로의 인덕터 |

**③ 필터 선택**

[M07 §5](../01_모듈/M07_필터와수동네트워크.md)의 기술 비교로 고릅니다.

| 기술 | 이 과제에서 |
|---|---|
| **SAW/BAW** | 2.4 GHz 대역통과에 표준. 삽입손실 1~2 dB |
| LTCC | 하모닉 필터에 적합. 싸고 전력 견딤 |
| 집중소자 LC | 정합·저역통과. 산포가 크다 |

> 📌 **필터의 삽입손실이 P1 예산에 들어 있던 값과 같은지 확인하십시오.** 예산은 1.5 dB를 가정했는데 실제 부품이 2.2 dB면, **잡음지수 예산이 0.7 dB 깨집니다.** 앞단 손실은 1:1로 들어옵니다.

**④ PA 선정**

| 확인 | 근거 |
|---|---|
| **P1dB** | 첨두 전력보다 위인가 (→ P1 ③) |
| 이득 | 드라이버와 합쳐 필요한 만큼인가 |
| **효율** | 백오프 상태에서의 효율. P1dB에서의 값이 아니다 |
| **열** | 손실 전력이 몇 W인가 (→ [M17 §11](../01_모듈/M17_보드설계와인증.md)) |
| 안정도 | 데이터시트의 안정도 자료 (→ [M08 §7](../01_모듈/M08_증폭기.md)) |
| 정합 | 응용노트의 정합 회로가 우리 보드에서도 되는가 |

> ⚠️ **효율은 백오프 상태에서 봐야 합니다.** 데이터시트의 "PAE 45 %"는 대개 P1dB 부근 값입니다. 9.5 dB 백오프하면 효율은 **훨씬 낮습니다**. 소비전력 상한 1.5 W에 드는지는 **백오프 상태의 효율**로 계산해야 합니다(→ [M08 §8](../01_모듈/M08_증폭기.md)).

### 부품을 정할 때마다

```bash
# capstone_check.py 의 RX_MODES / TX_LOSS / PA 를 실제 부품값으로 바꾸고
python3 scripts/capstone_check.py
```

> 📌 **한 부품을 바꿀 때마다 돌리십시오.** 마지막에 한꺼번에 돌리면 어느 부품이 예산을 깼는지 모릅니다. [M16 §9](../01_모듈/M16_DUT검증과튜닝과자동화.md)의 "한 번에 하나만 바꾼다"가 여기에도 적용됩니다.

## P2.2 산출물 ⑥ — 보드 설계

### 순서

[M17 §8](../01_모듈/M17_보드설계와인증.md)의 배치 순서를 그대로 따릅니다.

| 순서 | 이 과제에서 |
|---|---|
| 1 | **안테나 위치와 클리어런스** — 데이터시트가 정한 크기 |
| 2 | **RF 체인** — 안테나 → T/R 스위치 → 필터 → LNA → 믹서, **한 방향 직선** |
| 3 | **송신 경로** — 반대 방향으로. PA는 열이 빠질 곳에 |
| 4 | **RF ↔ 디지털 경계** |
| 5 | 전원 입력과 레귤레이터 — **RF 블록에서 멀리** |
| 6 | 커넥터·나사 구멍 |

### 스택업과 임피던스

| 결정 | 근거 | 어느 절 |
|---|---|---|
| 재료 | RF 배선 길이 × 손실이 예산 안인가 | [M17 §2](../01_모듈/M17_보드설계와인증.md) |
| 층 구성 | RF 층 바로 아래가 **통짜 접지** | [M17 §3](../01_모듈/M17_보드설계와인증.md) |
| L1–L2 두께 | 50 Ω 선폭이 부품 패드와 비슷해지는 값 | [M17 §3](../01_모듈/M17_보드설계와인증.md) |
| 선폭 | 계산 → **제조사 확인** → 쿠폰 | [M17 §4](../01_모듈/M17_보드설계와인증.md) |
| 비아 간격 | **λ/20을 계산해서** | [M17 §7](../01_모듈/M17_보드설계와인증.md) |

> 💡 **[M17의 L17-a 계산기](../01_모듈/M17_보드설계와인증.md)를 그대로 쓸 수 있습니다.** 재료별 손실·선폭·λ/20 비아 간격이 한 번에 나옵니다.

### P1이 넘겨준 격리 요구

> 📌 **P1 ④에서 나온 "클럭 격리 77 dB"가 여기서 설계 목표가 됩니다.**
>
> | 무엇으로 만드나 | 대략 |
> |---|---|
> | 배치 거리 (클럭을 RF에서 멀리) | 거리에 따라 |
> | 클럭을 **안쪽 층**으로, 짧게 | |
> | 접지면 연속성 — 리턴 패스 (→ [M17 §6](../01_모듈/M17_보드설계와인증.md)) | 크다 |
> | 비아 펜싱 (→ [M17 §7](../01_모듈/M17_보드설계와인증.md)) | |
> | 실드 캔 (→ [M17 §10](../01_모듈/M17_보드설계와인증.md)) | 마지막 수단 |
>
> **각 항목이 몇 dB를 낼지는 계산으로 못 냅니다.** 그래서 P3에서 **근접장 프로브로 확인**하고, 안 되면 P4에서 대책을 넣습니다. 여기서 할 일은 **77 dB를 목표로 두고 설계했다는 것을 기록**하는 것입니다.

### 전원 분배망

P1에는 없던 항목입니다. 여기서 처음 계산합니다.

| 단계 | 하는 일 | 어느 절 |
|---|---|---|
| 1 | **목표 임피던스** Z = ΔV/ΔI 를 레일마다 정한다 | [M17 §9](../01_모듈/M17_보드설계와인증.md) |
| 2 | 커패시터 값의 **계단을 촘촘히** 짠다 | [M06 §6](../01_모듈/M06_수동소자와공진.md) |
| 3 | |Z| 곡선을 그려 **반공진 봉우리**를 확인한다 | [M17 §9](../01_모듈/M17_보드설계와인증.md) |
| 4 | RF 레일을 분리한다 (페라이트 비드 또는 별도 LDO) | [M17 §8](../01_모듈/M17_보드설계와인증.md) |

> ⚠️ **PA 레일이 가장 까다롭습니다.** 송신 순간 큰 전류가 갑자기 흐릅니다. 그 과도 전류가 만드는 전압 강하가 다른 블록을 흔들면, 송신할 때마다 수신 성능이 흔들립니다(반이중이라 동시는 아니지만, 전환 직후가 문제입니다).

### 테스트 포인트

> 📌 **P3에서 잴 수 있게 지금 넣어야 합니다.** 나중에 못 넣습니다.

| 넣을 곳 | 형태 |
|---|---|
| RF 체인 각 단 사이 | **0 Ω 저항 자리** (떼면 분리됨) |
| 안테나 단자 | **커넥터** — 전도 측정을 하려면 필수 |
| 각 전원 레일 | 접지와 짝을 이룬 패드 |
| **임피던스 쿠폰** | 보드 가장자리 (→ [M17 §4](../01_모듈/M17_보드설계와인증.md)) |
| 클럭 배선 근처 | 근접장 프로브를 댈 여유 공간 |

> ⚠️ **안테나 단자 커넥터가 없으면 P3의 절반이 불가능합니다.** 전도(conducted) 측정을 못 하면 출력·하모닉·ACLR을 규격 셋업으로 잴 수 없고, OTA(공중 방사)만 남는데 그건 챔버가 필요합니다.

### 설계 리뷰

보드를 넘기기 전에 [M17 §15](../01_모듈/M17_보드설계와인증.md)의 체크리스트를 **한 줄씩** 대조합니다. 그 결과가 ⑪ 설계 리뷰 자료의 일부가 됩니다.

## P2.Q 확인 문제

<details>
<summary><b>Q1.</b> 예산에 맞는 LNA를 찾았는데 잡음지수가 Typ 0.8 dB, Min/Max 없음이다. 쓸 수 있는가?</summary>

**쓸 수 있지만, 예산에는 0.8을 넣으면 안 됩니다.**

**Typ은 보증이 아닙니다**(→ [M16 §2](../01_모듈/M16_DUT검증과튜닝과자동화.md)). 대개 평균이거나 대표 개체의 값이므로 **개체의 절반은 그보다 나쁩니다.**

**세 가지 대응**

| 대응 | 이 과제에서 |
|---|---|
| 제조사에 보증값 요청 | 학습 과제에서는 대개 답을 못 받는다 |
| **직접 측정** | P3에서 여러 개를 재 분포를 만든다. **가장 좋은 답** |
| **여유를 얹는다** | Typ + 0.5 dB = 1.3 dB 로 예산을 다시 돌린다 |

**세 번째를 택했다면 이렇게 적으십시오**: "LNA 잡음지수 1.3 dB로 가정 (데이터시트 Typ 0.8 + 0.5 dB 여유, 보증값 없음, 2026-08-21)"

**그리고 예산을 다시 돌립니다.** 0.5 dB가 더해지면 캐스케이드 NF가 3.86 → 약 4.3 dB가 되어 **요구 4 dB를 넘습니다.** 그러면 앞단 손실을 줄이거나(T/R 스위치를 더 좋은 것으로), 다른 LNA를 찾아야 합니다.

**이것이 P2에서 예산이 깨지는 전형적인 방식입니다.** 데이터시트의 예쁜 숫자를 그대로 믿으면 P3에서 알게 됩니다.
</details>

<details>
<summary><b>Q2.</b> PA 데이터시트에 "PAE 45 % @ P1dB"라고 적혀 있다. 소비전력 계산에 45 %를 쓰면 되는가?</summary>

**안 됩니다. 우리는 P1dB에서 쓰지 않습니다.**

P1의 예산에서 PA는 **9.5 dB 백오프** 상태로 동작합니다. 그 상태의 효율은 P1dB에서보다 **훨씬 낮습니다.**

**대략적인 관계** (→ [M08 §8](../01_모듈/M08_증폭기.md)): A급·AB급 증폭기의 효율은 출력 전력에 거의 비례해 떨어집니다. 9.5 dB 백오프면 출력이 약 1/9이므로, 효율도 그만큼 내려갑니다.

| 상태 | 출력 | 대략적인 효율 |
|---|---|---|
| P1dB | +32 dBm (1.6 W) | 45 % |
| 9.5 dB 백오프 | +22.5 dBm (0.18 W) | 5~10 %대 |

**소비전력 계산**: 출력 0.18 W ÷ 효율 0.08 ≈ **2.2 W** — 상한 1.5 W를 넘습니다.

**대응**

| 안 | 효과 |
|---|---|
| **출력을 낮춘다** (+17 dBm) | EIRP 모순과 함께 풀린다 (→ P1) |
| **도허티 구조** | 백오프 지점에 두 번째 효율 봉우리 (→ [M08 §8](../01_모듈/M08_증폭기.md)) |
| **CFR** 로 백오프를 줄인다 | PAPR 10 → 7 dB면 백오프도 3 dB 줄어든다 |

> **데이터시트의 효율은 대개 가장 좋은 조건의 값입니다.** 우리 동작점의 값을 그래프에서 읽거나, 없으면 직접 재야 합니다.
</details>

<details>
<summary><b>Q3.</b> 보드에 안테나 단자 커넥터를 안 넣고 칩 안테나를 바로 붙였다. P3에서 무엇이 문제인가?</summary>

**전도 측정을 할 수 없습니다. 즉 P3의 대부분이 불가능해집니다.**

| 측정 | 커넥터 없이 가능한가 |
|---|---|
| 송신 출력 | **불가** — 공중 방사만, 챔버 필요 |
| 하모닉·ACLR | **불가** — 같은 이유 |
| 수신 감도 | **불가** — 신호를 주입할 곳이 없다 |
| 잡음지수 | **불가** |
| S11 | **불가** |
| 소비전력 | 가능 |

**대응**

1. **RF 커넥터를 넣는다** — 가장 확실합니다. 안테나로 가는 선로 중간에 0 Ω 저항 자리를 두고, 옆에 커넥터를 답니다. 시험할 때는 0 Ω을 떼고 커넥터를, 실사용에는 반대로 합니다
2. **평가용 보드를 따로** 만든다 — 커넥터판과 안테나판
3. **프로브 패드**를 둔다 — 정확도는 떨어지지만 상대 비교는 된다

> 📌 **이것이 [M17 §12](../01_모듈/M17_보드설계와인증.md)에서 "테스트 포인트를 반드시 넣으라"고 한 이유입니다.** 보드가 나온 뒤에는 못 넣습니다. 인증 시험소도 대개 **전도 측정용 커넥터를 요구**합니다.
</details>
