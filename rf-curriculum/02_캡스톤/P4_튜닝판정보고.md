## P4.0 이 단계의 성격

> **P1~P3은 "만들고 재는" 일이었습니다. P4는 "판단하고 남기는" 일입니다.**

실무에서 가장 자주 요구되는데 가장 안 가르치는 단계입니다. 그리고 **채점 비중이 가장 큽니다** — L3과 L4를 가르는 것이 여기서 나옵니다.

## P4.1 산출물 ⑨ — 튜닝 기록

### 먼저: 튜닝할 것인가, 설계를 고칠 것인가

[M16 §8](../01_모듈/M16_DUT검증과튜닝과자동화.md)의 판별을 먼저 합니다. **가장 비싼 실수는 고칠 수 없는 것을 며칠씩 튜닝하는 것**입니다.

| P3에서 나온 증상 | 튜닝으로 되나 | 판별 |
|---|---|---|
| \|S11\| 이 −8 dB (목표 −15 dB) | **된다** | 스미스 차트에서 목표까지 가깝다 |
| 이득이 1~2 dB 모자람 | 대개 **된다** | 바이어스·정합으로 회복되는지 |
| 이득이 10 dB 모자람 | **안 된다** | 부품 선택이나 회로 구조 |
| 잡음지수가 2 dB 나쁨 | **대개 안 된다** | 앞단 손실이나 배치 |
| 대역이 좁음 | **안 된다** | 정합 단수를 늘려야 |
| 발진 | **안 된다** | 안정도. 회로를 고쳐야 |
| 클럭 스퍼 | **안 된다** | 배치·접지 — 보드 개정 |

> ⚠️ **"조금만 더 만지면 될 것 같다"가 가장 위험한 신호입니다.** 두세 번 해서 방향이 안 잡히면, **왜 안 되는지를 먼저 이해**해야 합니다.

### 튜닝 기록 양식

| 시도 | 무엇을 바꿈 | 전 | 후 | 판단 | 되돌릴 수 있나 |
|---|---|---|---|---|---|
| 0 | (기준) | \|S11\| −8.2 dB | — | — | — |
| 1 | C3 1.0 → 1.5 pF | −8.2 dB | −11.4 dB | 방향 맞음 | 예 |
| 2 | C3 1.5 → 2.2 pF | −11.4 dB | −9.8 dB | 지나침 | 예 |
| 3 | C3 = 1.8 pF | −11.4 dB | −16.1 dB | **목표 달성** | 예 |

> 📌 **세 가지 규칙** (→ [M16 §6·§9](../01_모듈/M16_DUT검증과튜닝과자동화.md))
>
> 1. **한 번에 하나만** 바꾼다 — 두 개를 동시에 바꾸고 좋아지면 무엇이 효과였는지 영원히 모른다
> 2. **매번 기록**한다 — 스미스 차트 위치도 함께
> 3. **되돌릴 수 있게** 한다 — 몇 바퀴 돌렸는지, 어떤 값을 뗐는지

### 정합 튜닝의 순서

[M16 §6](../01_모듈/M16_DUT검증과튜닝과자동화.md)입니다.

1. **먼저 실수부**를 50 Ω으로 (병렬 소자)
2. **그다음 허수부**를 상쇄 (직렬 소자)
3. 계산으로 값을 정하고 **E12 계열에서 가장 가까운 값**으로
4. **두 소자가 모두 양수**로 나오는 조합인지 확인 — 음의 인덕턴스는 없다

### 바이어스 튜닝

[M16 §7](../01_모듈/M16_DUT검증과튜닝과자동화.md)입니다. 이 과제에서 특히 쓸 곳:

| 어디 | 무엇을 얻고 무엇을 내주나 |
|---|---|
| **LNA 정지 전류** | 잡음지수 최적점과 IIP3·소비전력의 절충 |
| **PA 정지 전류** | 효율과 선형성(EVM·ACLR)의 절충 |

> ⚠️ **바이어스를 바꿨으면 데이터시트가 무효입니다.** 데이터시트의 모든 값은 그 조건 줄의 전류에서 잰 것입니다. **직접 다시 재야** 합니다 — 그리고 P1의 예산표도 그 값으로 고쳐야 합니다.

## P4.2 산출물 ⑩ — 적합성 판정서

### 표의 모양

| 항목 | 요구 | 판정 규칙 | 측정값 ± U | 합격선 | **판정** |
|---|---|---|---|---|---|
| RX 잡음지수 (고이득) | ≤ 4.0 dB | 엄격 수용, GB 0.5 | 3.7 ± 0.55 dB | 3.5 dB | **불합격** |
| RX IIP3 (저이득) | ≥ −10 dBm | 단순 수용 | +1.2 ± 1.0 dBm | −10 dBm | 합격 |
| TX 출력 | +17 dBm ± 1 | 단순 수용 | +17.3 ± 0.4 dBm | | 합격 |
| **EIRP** | ≤ 20 dBm | **엄격 수용, GB 1.0** | 19.3 ± 0.5 dBm | 19.0 dBm | **불합격** |
| TX EVM | ≤ 3 % | 엄격 수용 | | | |
| 하모닉 | 규격 이하 | **엄격 수용** | | | |

> 📌 **판정 규칙 칸이 없으면 이 표는 의미가 없습니다.** "3.7 dB, 요구 4.0 dB"만 보면 합격 같지만, 불확도 0.55 dB를 넣고 엄격 수용으로 판정하면 **불합격**입니다(→ [M16 §5](../01_모듈/M16_DUT검증과튜닝과자동화.md)).

### 판정 규칙을 어떻게 정하는가

| 항목 종류 | 규칙 | 왜 |
|---|---|---|
| **규제** (EIRP·ACLR·하모닉·대역외) | **엄격 수용** | 넘으면 팔 수 없다. 시험소 불확도까지 우리가 진다 |
| 고객과 계약한 스펙 | 계약서에 정한 대로 | 미리 합의해야 한다 |
| 내부 스펙 | 단순 수용도 가능 | 근거를 적을 것 |
| 안전 관련 | **엄격 수용** | |

> ⚠️ **판정 규칙은 재고 나서 정하는 것이 아닙니다.** P3의 시험 계획서에서 미리 정했어야 합니다. 결과를 보고 규칙을 고르면 그것은 판정이 아니라 **결과 맞추기**입니다.

### 불합격 항목의 처리

| 무엇 | 적을 것 |
|---|---|
| **원인** | 어느 단·어느 요인인가. 이분 탐색 결과 |
| **영향** | 이 항목이 안 되면 무엇을 못 하는가 |
| **대책** | 튜닝으로 되나, 부품 교체인가, 보드 개정인가 |
| **일정과 비용** | 대책의 대가 |
| **임시 조치** | 그때까지 어떻게 할 것인가 (출력을 낮춰 쓴다 등) |

> 📌 **불합격을 적는 것이 감점이 아닙니다.** 불합격을 **안 적거나**, 적고도 원인·대책이 없는 것이 감점입니다. 실무에서 초도 시제품이 전 항목 합격하는 일은 거의 없습니다.

## P4.3 산출물 ⑪ — 설계 리뷰 자료

### 구성

| 절 | 내용 | 분량 |
|---|---|---|
| 1 | **요구와 협의 결과** — 무엇을 왜 바꿨는가 | 1~2장 |
| 2 | 아키텍처 선택과 그 대가 | 1장 |
| 3 | **예산 ↔ 실측 대조** — 어디가 얼마나 달랐고 왜인가 | 2장 |
| 4 | 판정 결과 요약 | 1장 |
| 5 | **다시 한다면 무엇을 바꾸겠는가** | 1~2장 |
| 6 | **못 한 것과 그 이유** | 1장 |

> 📌 **5절과 6절이 L3과 L4를 가릅니다.** 1~4절은 한 일의 보고이고, 5~6절은 **판단**입니다.

### 5절에 적을 만한 것

| 질문 | 예 |
|---|---|
| 요구 협의를 다시 한다면? | "감도를 −91이 아니라 −90 dBm으로 받았어야. 온도 마진이 빠듯했다" |
| 부품 선택을 다시 한다면? | "LNA를 Typ만 있는 것 말고 보증값 있는 것으로. 예산이 두 번 깨졌다" |
| 배치를 다시 한다면? | "스위칭 레귤레이터를 더 멀리. 클럭 격리가 예상보다 부족했다" |
| 측정을 다시 한다면? | "쿠폰을 먼저 쟀어야. S11 이상의 원인을 사흘 뒤에 알았다" |
| 순서를 다시 한다면? | "P2에 시간을 너무 썼다. P3·P4가 급했다" |

### 6절 — 못 한 것

> ⚠️ **못 한 것을 안 적는 것도 감점입니다.**

| 못 한 것 | 왜 | 그래서 확인 못 된 것 |
|---|---|---|
| 위상잡음 측정 | 장비 없음 | 도달 목표 G5의 일부 |
| 온도 시험 | 챔버 없음 | 온도 마진 미검증 |
| 복사 방출 절대값 | 챔버 없음 | 인증 통과 여부 |
| 양산 산포 | 시료 3개뿐 | 통계적 판정 |

## P4.4 P4 완료 판정

| | 확인 |
|---|---|
| ☐ | 튜닝 전에 **튜닝 가능 여부를 판별**했다 |
| ☐ | 튜닝 기록이 **한 번에 하나씩**, 전후 값과 함께 있다 |
| ☐ | 바이어스를 바꿨다면 **예산표도 고쳤다** |
| ☐ | 판정서에 **항목마다 판정 규칙**이 적혀 있다 |
| ☐ | 규제 항목은 **엄격 수용**으로 판정했다 |
| ☐ | 판정 규칙을 **P3에서 미리** 정한 것이다 |
| ☐ | 불합격 항목에 원인·영향·대책·일정이 있다 |
| ☐ | 리뷰 자료에 **"다시 한다면"** 절이 있다 |
| ☐ | 리뷰 자료에 **"못 한 것"** 절이 있다 |
| ☐ | 모든 숫자가 데이터시트·측정·계산 중 하나로 **추적 가능**하다 |

## P4.Q 확인 문제

<details>
<summary><b>Q1.</b> 잡음지수가 3.7 dB로 나왔다. 요구는 4.0 dB다. 합격인가?</summary>

**판정 규칙을 먼저 정해야 답할 수 있습니다. 그리고 이 항목은 P3에서 이미 정했어야 합니다.**

확장불확도를 ±0.55 dB (k = 2)라고 하면:

| 규칙 | 합격선 | 판정 |
|---|---|---|
| **단순 수용** | 4.0 dB | 3.7 ≤ 4.0 → **합격** |
| **엄격 수용** (GB = U = 0.55) | 3.45 dB | 3.7 > 3.45 → **불합격** |
| 엄격 거부 | 4.55 dB | 합격 |

**참값이 4.0을 넘을 확률**: 3.7에서 4.0까지는 0.3 dB이고 표준불확도는 0.275 dB이므로 약 1.09σ입니다. 참값이 4.0을 넘을 확률은 **약 14 %**입니다.

**실무의 답**: 이 상황은 **경계**입니다.

1. 내부 스펙이라면 단순 수용으로 합격 처리하되, **위험 14 %를 기록**한다
2. 고객 스펙이라면 **미리 합의한 규칙**을 따른다
3. 어느 쪽이든 근본적으로는 **마진이 얇다**는 신호다 (예산은 3.86, 요구는 4.0 — 애초에 0.14 dB뿐이었다)

> 📌 **P1에서 잡음지수 마진이 0.14 dB뿐이었던 것이 여기서 돌아옵니다.** 얇은 마진은 측정 불확도를 감당하지 못합니다. 가드밴딩은 **얇다는 사실을 드러낼 뿐, 안전하게 만들어 주지 않습니다**(→ [M16 §5](../01_모듈/M16_DUT검증과튜닝과자동화.md)).
</details>

<details>
<summary><b>Q2.</b> \|S11\|을 −8 dB에서 −16 dB로 튜닝했다. 그런데 잡음지수가 0.4 dB 나빠졌다. 왜인가?</summary>

**전력 정합점과 잡음 정합점이 다르기 때문입니다.**

LNA에는 잡음이 최소가 되는 **최적 소스 반사계수 Γ_opt** 가 따로 있고, 이것은 켤레 정합점(입력 반사가 최소인 점)과 **대개 일치하지 않습니다**(→ [M08 §3](../01_모듈/M08_증폭기.md) · [M03](../01_모듈/M03_S파라미터와스미스차트.md)).

| 무엇에 맞추나 | 얻는 것 | 잃는 것 |
|---|---|---|
| **켤레 정합** (S11 최소) | 반사 적음, 이득 최대 | 잡음지수 |
| **잡음 정합** (Γ_opt) | 잡음지수 최소 | S11이 나빠짐, 이득 조금 |

**어느 쪽을 택할 것인가**

| 상황 | 선택 |
|---|---|
| 수신 첫 단 LNA | **잡음 정합 우선.** 감도가 목적이다 |
| 앞에 필터가 있어 반사가 문제 | 절충. 필터는 반사에 민감하다 |
| 이득이 모자람 | 켤레 정합 쪽으로 |

**이 과제에서는**: LNA 앞에 대역통과 필터가 있습니다. 필터는 종단 임피던스가 나쁘면 **통과대역 특성이 흔들립니다**(→ [M07](../01_모듈/M07_필터와수동네트워크.md)). 그래서 S11을 아주 나쁘게 둘 수는 없습니다.

**실무의 절충**: \|S11\| −10 dB 정도를 확보하면서 잡음지수를 최우선합니다. −16 dB까지 밀어붙여 잡음지수를 0.4 dB 내주는 것은 **손해**입니다 — 잡음지수 마진이 0.14 dB뿐이었다면 이 튜닝으로 요구를 못 맞추게 됩니다.

> **튜닝 기록에 이것을 적으십시오.** "S11을 −16까지 개선했으나 NF가 0.4 dB 악화되어 −11 dB 지점으로 되돌림"이 좋은 기록입니다.
</details>

<details>
<summary><b>Q3.</b> 초도 시제품에서 14개 항목 중 4개가 불합격이다. 실패한 프로젝트인가?</summary>

**아닙니다. 정상입니다. 판정하는 것이 실패가 아니라, 판정을 못 하는 것이 실패입니다.**

실무에서 초도 시제품이 전 항목 합격하는 일은 거의 없습니다. 초도의 목적은 **합격이 아니라 학습**입니다.

**평가받는 것은 이것입니다.**

| 질문 | L2 | L3 |
|---|---|---|
| 불합격을 찾았는가 | 찾았다 | 찾았다 |
| 원인을 아는가 | 모른다 | **어느 단·어느 요인인지 좁혔다** |
| 대책이 있는가 | "다시 해 보겠다" | **튜닝/부품/보드 중 무엇인지 판별했다** |
| 위험을 아는가 | — | **못 고치면 무엇을 못 하는지 안다** |

**불합격 4건을 이렇게 정리하면 L3입니다.**

| 항목 | 원인 | 대책 | 등급 |
|---|---|---|---|
| RX NF 3.7 (GB 넘음) | 필터 삽입손실이 예산 1.5 → 실측 2.1 dB | 저손실 필터로 교체. 예산 재계산 | 부품 |
| EIRP 19.3 (GB 넘음) | 안테나 이득이 데이터시트보다 높음 | 출력 1 dB 하향 | 펌웨어 |
| 클럭 스퍼 | 클럭 배선이 RF 접지 위를 지남 | 배선 층 변경 | **보드 개정** |
| EVM 3.4 % | PA 백오프 부족 | CFR 도입 또는 출력 하향 | 펌웨어 |

> 📌 **네 건 중 보드 개정이 필요한 것은 하나뿐**임을 밝힌 것이 이 정리의 가치입니다. 그것을 모르면 "보드를 다시 만들어야 한다"고 보고하게 되고, 그것은 2~6주와 비용을 뜻합니다.
</details>

## P4.5 한 장 요약

| 무엇 | 한 줄 |
|---|---|
| 튜닝 전에 | **튜닝으로 될 일인지부터 판별**한다 |
