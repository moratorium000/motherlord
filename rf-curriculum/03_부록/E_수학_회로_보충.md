## E.0 이 문서는 무엇인가

설계서 §1.1은 피교육자를 **전기전자공학 초심자**로 가정하고, 다음만 전제합니다.

- 옴의 법칙, 직렬/병렬, 키르히호프 법칙
- 사인파와 위상의 개념 (계산은 서툴러도 됨)
- 복소수의 실수부/허수부, 크기/위상
- 로그의 기본 성질
- **전자기학은 전제하지 않습니다**

문제는 "안다고 가정"만 하고 확인하지 않으면, 정작 M02(전송선로)에 가서 복소 임피던스가 나올 때 진도가 막힌다는 점입니다. 그래서 이 문서는 두 부분으로 되어 있습니다.

| 절 | 내용 |
|---|---|
| **E.1** | **자가진단 20문항** — 지금 내가 어디가 비었는지 확인 |
| **E.2 ~ E.6** | 비어 있는 부분을 채우는 최소한의 보충 |

> **중요**: 이 문서를 처음부터 끝까지 읽을 필요는 **없습니다.** 자가진단에서 틀린 문항이 가리키는 절만 보십시오. RF를 배우러 왔는데 수학 복습에 두 달을 쓰면 목적을 잃습니다.

## E.2 회로 기초

### E.2.1 옴의 법칙과 전력

```
V = I × R          전압 = 전류 × 저항
P = V × I = I²R = V²/R
```

**RF에서 왜 중요한가**: RF는 거의 모든 것을 **전력**으로 이야기합니다. 전압이 아니라 전력을 기준으로 삼는 이유는, 전송선로에서는 위치에 따라 전압이 달라지지만 **전달되는 전력은 보존**되기 때문입니다. (→ M02)

`P = V²/R` 에서 **전력이 전압의 제곱에 비례**한다는 점을 기억하십시오. 이것이 dB에서 전력은 10 log, 전압은 20 log를 쓰는 이유입니다. (→ M01)

### E.2.2 직렬과 병렬

| | 저항 | 합성 |
|---|---|---|
| 직렬 | R₁, R₂ | R₁ + R₂ |
| 병렬 | R₁, R₂ | (R₁ × R₂) / (R₁ + R₂) |

같은 값 두 개를 병렬로 하면 절반입니다. 100 Ω ∥ 100 Ω = 50 Ω.

### E.2.3 최대 전력 전달 정리

전원의 내부 저항이 R_s일 때, 부하 저항이 **R_L = R_s** 일 때 부하가 받는 전력이 최대입니다.

**RF에서 왜 중요한가**: 이것이 "임피던스 정합"의 출발점입니다. 다만 RF에서는 저항이 아니라 **복소 임피던스**를 다루므로, 조건이 `Z_L = Z_s*` (켤레 복소수)로 바뀝니다. (→ M03)

주의할 점: **정합의 목적은 늘 최대 전력 전달이 아닙니다.** LNA에서는 잡음이 최소가 되는 정합을 따로 씁니다. (→ M08)

## E.3 교류와 위상

### E.3.1 사인파의 3요소

```
v(t) = A · sin(2πft + φ)
        │        │      └─ 위상 (φ): 언제 시작하는가
        │        └──────── 주파수 (f): 1초에 몇 번 흔들리는가
        └───────────────── 진폭 (A): 얼마나 크게 흔들리는가
```

**주기** T = 1/f. 2.4 GHz면 T = 1/(2.4×10⁹) ≈ 0.417 ns 입니다.

### E.3.2 위상이란

위상차 90°는 **한 주기의 1/4만큼 어긋났다**는 뜻입니다. 360°가 한 주기이기 때문입니다.

RF에서 위상이 결정적인 이유: 두 신호를 합칠 때 **같은 위상이면 커지고, 180° 어긋나면 상쇄**됩니다. 반사파와 진행파가 만들어 내는 정재파도 이 원리입니다. (→ M02)

### E.3.3 L과 C의 임피던스

| 소자 | 임피던스 | 주파수가 올라가면 | 전류와 전압 |
|---|---|---|---|
| 저항 R | R | 그대로 | 동상 |
| 인덕터 L | jωL = j·2πf·L | **커진다** | 전류가 90° 뒤처짐 |
| 커패시터 C | 1/(jωC) = −j/(2πfC) | **작아진다** | 전류가 90° 앞섬 |

외우는 법: **인덕터는 변화를 싫어해서** 고주파를 막고, **커패시터는 변화를 좋아해서** 고주파를 통과시킵니다.

> **초심자 실수 1순위**: 이 표는 **이상적인 소자**에 대한 것입니다. 실제 부품에는 기생 성분이 있어서, 어느 주파수 위에서는 커패시터가 인덕터처럼 행동합니다. 이것이 자기공진주파수(SRF)입니다. (→ M06)

### E.3.4 RMS(실효값)

사인파에서 `RMS = 첨두값 / √2 ≈ 0.707 × 첨두값`

**RF에서 왜 중요한가**: 전력계는 보통 RMS 기준으로 읽습니다. 그런데 OFDM 같은 현대 변조 신호는 사인파가 아니라서 이 √2 관계가 성립하지 않습니다. 그래서 첨두와 평균의 비(PAPR)를 따로 관리합니다. (→ M13)

## E.4 복소수 — RF에서 가장 중요한 수학 도구

### E.4.1 왜 복소수를 쓰는가

RF에서 신호를 다룰 때는 **크기**와 **위상** 두 가지를 동시에 추적해야 합니다. 복소수는 이 두 정보를 **숫자 하나**에 담습니다.

```
        허수축
          │
        4 ┤      ● 3 + 4j
          │     ╱│
          │    ╱ │   크기 = 5
          │   ╱  │   위상 ≈ 53.1°
          │  ╱   │
        ──┼─────┼──── 실수축
          │  3
```

### E.4.2 두 가지 표현

| 표현 | 형태 | 언제 편한가 |
|---|---|---|
| 직교 형식 | a + jb | **더하기·빼기** 할 때 |
| 극 형식 | M∠θ 또는 M·e^(jθ) | **곱하기·나누기** 할 때 |

변환:
```
크기  M = √(a² + b²)          →  |3 + 4j| = √(9+16) = 5
위상  θ = arctan(b / a)        →  arctan(4/3) ≈ 53.1°
```

### E.4.3 곱셈의 의미 — 이것만 이해하면 됩니다

복소수를 곱하면:
- **크기끼리 곱해지고**
- **위상끼리 더해집니다**

이것이 RF에서 복소수를 쓰는 진짜 이유입니다. 신호가 회로를 지나가는 것은 "크기가 얼마 곱해지고 위상이 얼마 돌아가는 것"인데, 이것이 정확히 복소수 곱셈입니다.

특히 크기가 1인 복소수 e^(jθ)를 곱하면 **크기는 그대로, 위상만 θ만큼 회전**합니다. 전송선로에서 파가 나아가는 것을 이렇게 표현합니다. (→ M02)

### E.4.4 오일러 공식

```
e^(jθ) = cos θ + j sin θ
```

지금은 **"e^(jθ)는 단위원 위에서 각도 θ인 점"** 정도로만 이해해도 충분합니다. 스미스 차트에서 원을 도는 것이 바로 이것입니다. (→ M03)

### E.4.5 켤레 복소수

`(a + jb)* = a − jb` — 허수부의 부호만 바꿉니다.

**RF에서 왜 중요한가**: 최대 전력 전달 조건이 `Z_L = Z_s*` 이기 때문입니다. 소스가 유도성(+j)이면 부하는 용량성(−j)이어야 서로 상쇄되어 최대 전력이 전달됩니다. (→ M03)

## E.5 로그 — M01 시작 전 필수

### E.5.1 기본 성질

```
log₁₀(10) = 1        log₁₀(100) = 2       log₁₀(1000) = 3
log₁₀(1)  = 0        log₁₀(0.1) = −1      log₁₀(0.01) = −2

log(A × B) = log A + log B     ← 곱셈이 덧셈이 된다 ★
log(A / B) = log A − log B
log(Aⁿ)    = n · log A
```

★ 표시한 성질이 dB의 존재 이유입니다. 증폭기 이득 100배와 케이블 손실 1/10배를 곱하는 대신, 20 dB와 −10 dB를 더해 10 dB로 끝냅니다. (→ M01)

### E.5.2 외워 두면 평생 쓰는 값

| x | log₁₀(x) | dB로 (전력) |
|---|---|---|
| 1 | 0 | 0 dB |
| **2** | **0.301** | **3 dB** |
| 3 | 0.477 | 4.8 dB |
| 4 = 2² | 0.602 | 6 dB |
| **5 = 10/2** | **0.699** | **7 dB** |
| 8 = 2³ | 0.903 | 9 dB |
| **10** | **1** | **10 dB** |

**암산법**: log(2) ≈ 0.3 과 log(10) = 1 만 알면 나머지는 조합으로 나옵니다.
- log(4) = log(2×2) = 0.3 + 0.3 = 0.6
- log(5) = log(10/2) = 1 − 0.3 = 0.7
- log(20) = log(2×10) = 0.3 + 1 = 1.3

이 감각이 붙으면 **"3 dB면 2배, 10 dB면 10배, 20 dB면 100배"** 를 즉시 떠올릴 수 있습니다. RF 엔지니어의 기본기입니다.

## E.6 단위와 크기 감각

### E.6.1 접두어

| 접두어 | 기호 | 배수 | RF에서 쓰이는 곳 |
|---|---|---|---|
| 기가 | G | 10⁹ | 주파수 (2.4 GHz) |
| 메가 | M | 10⁶ | 주파수, 대역폭 (20 MHz) |
| 킬로 | k | 10³ | 대역폭 (100 kHz) |
| 밀리 | m | 10⁻³ | 전력 (1 mW) |
| 마이크로 | μ | 10⁻⁶ | 전압 (μV), 시간 |
| 나노 | n | 10⁻⁹ | 인덕턴스 (nH), 시간 (ns) |
| 피코 | p | 10⁻¹² | 커패시턴스 (pF) |

### E.6.2 빛의 속도와 파장 — 손에 익혀야 할 감각

```
c ≈ 3 × 10⁸ m/s = 30 cm/ns
```

**진공에서 전파는 1 나노초에 약 30 cm를 갑니다.** 이 감각 하나로 많은 것이 풀립니다.

```
파장 λ = c / f
```

| 주파수 | 자유공간 파장 | 감각 |
|---|---|---|
| 100 MHz (FM 라디오) | 3 m | 사람 키보다 큼 |
| 900 MHz | 33 cm | 팔 길이 |
| **2.4 GHz (Wi-Fi)** | **12.5 cm** | **손바닥** |
| 5 GHz | 6 cm | 손가락 |
| 28 GHz (5G 밀리미터파) | 1.07 cm | 손톱 |

> **RF의 출발점**: 회로 크기가 파장에 비할 만큼 커지면, 전선 한 가닥에서도 위치마다 전압이 달라집니다. 그때부터 회로 이론이 깨지고 전송선로 이론이 필요해집니다. 대략 **λ/10** 이 경계로 쓰입니다. 2.4 GHz에서 λ/10은 약 1.25 cm — **PCB 위 배선 1 cm가 이미 "긴 선"** 이라는 뜻입니다. (→ M00, M02)

기판 위에서는 유전체 때문에 파장이 더 짧아집니다. 대략 `λ_기판 ≈ λ_자유공간 / √(유효 유전율)` 이므로, FR-4(유효 Dk ≈ 3.5 부근)에서는 절반 남짓으로 줄어듭니다. (→ M02, M17)

## E.8 이 문서에서 다루지 **않는** 것

정직하게 밝힙니다. 다음은 이 커리큘럼의 선수 지식이 **아니며**, 필요한 최소한만 해당 모듈에서 그때그때 도입합니다.

| 주제 | 왜 빼는가 | 어디서 최소한만 다루는가 |
|---|---|---|
| 맥스웰 방정식 | 초심자에게 진입 장벽만 되고, 실무 RF 설계에서 직접 푸는 일이 드묾 | M02(파동의 직관), M10(방사의 직관) |
| 미분방정식 풀이 | 결과식만 알면 설계·측정이 가능 | 필요 시 접이식 블록으로 분리 |
| 푸리에 변환의 수학적 전개 | 개념(시간↔주파수)만 있으면 충분 | M05(스펙트럼의 의미) |
| 확률·통계 이론 | 필요한 부분만 실용적으로 | M13(BER), M16(시료 수) |
| 반도체 물성 | 소자를 만들지 않고 쓰는 관점 | M08(트랜지스터의 동작 개념) |

> 나중에 더 깊이 들어가고 싶다면 설계서 §11.3의 MIT OCW 6.013 / 6.661, Steer 시리즈를 참고하십시오.
