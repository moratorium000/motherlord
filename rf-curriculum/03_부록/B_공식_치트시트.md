| $v_p = c/\sqrt{\varepsilon_\text{eff}}$ | 위상 속도 | |

| $\Gamma = \dfrac{Z_L - Z_0}{Z_L + Z_0}$ | 반사계수 | **복소수.** 크기만 쓰면 위상 정보를 잃는다 |
| $\mathrm{VSWR} = \dfrac{1+\lvert\Gamma\rvert}{1-\lvert\Gamma\rvert}$ | 정재파비 | |

| $\lvert\Gamma\rvert^2$ | 반사 전력 비율 | |
| $Z_\text{in} = Z_0\dfrac{Z_L + jZ_0\tan\beta\ell}{Z_0 + jZ_L\tan\beta\ell}$ | 무손실 선로 입력 임피던스 | λ/2면 $Z_L$ 그대로, λ/4면 $Z_0^2/Z_L$ |

## B.4 S-파라미터와 정합 — 소유 [M03](../01_모듈/M03_S파라미터와스미스차트.md)

| 공식 | 뜻 | 주의 |
|---|---|---|
| $S_{11} = b_1/a_1\big\vert_{a_2=0}$ | 입력 반사 | **다른 포트가 정합 종단**일 때만 |
| $S_{21} = b_2/a_1\big\vert_{a_2=0}$ | 순방향 전달 | |
| $\lvert S_{21}\rvert\,[\mathrm{dB}] = 20\log_{10}\lvert S_{21}\rvert$ | | 20log (진폭이므로) |
| $\lvert S_{11}\rvert^2 + \lvert S_{21}\rvert^2 = 1$ | **무손실** 2포트 | 손실이 있으면 < 1 |
| $\Gamma = \dfrac{Z-Z_0}{Z+Z_0}$, $Z = Z_0\dfrac{1+\Gamma}{1-\Gamma}$ | 스미스 차트의 두 방향 | |
| $Z_T = \sqrt{Z_0 R_L}$ | λ/4 변환기 | 실수 부하일 때 |

### L형 정합 (직렬 L → 병렬 C, $R_L < Z_0$)

$$Q = \sqrt{\frac{Z_0}{R_L} - 1} \qquad X_s = QR_L - X_L \qquad B_p = \frac{Q}{Z_0}$$

$$L = \frac{X_s}{2\pi f} \qquad C = \frac{B_p}{2\pi f}$$

**예제** ($Z_0$ 50 Ω, 부하 20 − j30 Ω, 2.4 GHz): Q = 1.2247 → $X_s$ = 54.49 Ω → **L = 3.614 nH**, $B_p$ = 24.49 mS → **C = 1.624 pF**

> ⚠️ **근이 둘 나오면 다음 단계까지 계산해 보고 고르십시오.** 한쪽을 고르면 **음의 인덕턴스**가 나옵니다. 그런 부품은 없습니다(→ [M16 §6](../01_모듈/M16_DUT검증과튜닝과자동화.md)).

> 📌 **정합 대역폭은 Q에 반비례합니다.** Q가 크면(임피던스 차이가 크면) 좁습니다. 넓히려면 단수를 늘립니다.

| $\mathrm{IM3}_\text{아래} = 2(\mathrm{IIP3} - P_\text{in})$ | IM3가 기본파보다 몇 dB 아래 | 입력 1 dB↑ → **2 dB 악화** |
| $\mathrm{IIP3} \approx P_{1\mathrm{dB}} + 9\text{~}10$ | 경험칙 | **경험칙이다.** 부품마다 다르다 |
| $\mathrm{OIP3} = \mathrm{IIP3} + G$ | | |
| $\Delta = S_{11}S_{22}-S_{12}S_{21}$ | | |
| $K = \dfrac{1-\lvert S_{11}\rvert^2-\lvert S_{22}\rvert^2+\lvert\Delta\rvert^2}{2\lvert S_{12}S_{21}\rvert}$ | 안정도 계수 | **K > 1 이고 \|Δ\| < 1** 이어야 무조건 안정 |
| $\mu = \dfrac{1-\lvert S_{11}\rvert^2}{\lvert S_{22}-\Delta S_{11}^*\rvert + \lvert S_{12}S_{21}\rvert}$ | 안정도 (한 지표로) | **μ > 1** 이면 무조건 안정 |

## B.7 주파수 변환과 발진기 — 소유 [M09](../01_모듈/M09_주파수변환과신호원.md)

| 공식 | 뜻 | 주의 |
|---|---|---|
| $\cos A\cos B = \tfrac12[\cos(A-B)+\cos(A+B)]$ | 곱하면 합·차가 나온다 | 믹서의 전부 |
| $f_\text{image} = f_\text{LO} + f_\text{IF} = f_\text{RF} + 2f_\text{IF}$ | 이미지 (하이사이드 LO) | 로우사이드면 $f_\text{RF} - 2f_\text{IF}$ |
| $f_\text{out} = \lvert mf_\text{RF} \pm nf_\text{LO}\rvert$ | 스퍼 | m, n = 0,1,2,3,… |
| $f_\text{in} = \dfrac{nf_\text{LO} \pm f_\text{IF}}{m}$ | 어떤 입력이 IF에 떨어지나 | 스퍼 차트의 역방향 |
| $f_\text{out} = (N/R)\,f_\text{ref}$ | PLL 출력 | |

| $\sigma_\phi = \sqrt{2\int_{f_1}^{f_2}L(f)\,df}$ | RMS 위상 오차 [rad] | $L(f)$는 **선형**(dBc/Hz 아님) |
| $\sigma_t = \sigma_\phi/(2\pi f_0)$ | RMS 지터 [s] | |
| $P_\text{잡음} = P_\text{간섭} + L(\Delta f) + 10\log_{10}B$ | 상호혼합 | |

### 클럭 하모닉

$$n = \frac{f_\text{대상}}{f_\text{클럭}} \quad\text{이 정수에 가까우면 그 하모닉이 대역에 있다}$$

> ⚠️ **클럭 주파수가 대역폭보다 낮으면 대역 내 하모닉을 피할 수 없습니다.** 하모닉 간격이 곧 클럭 주파수이기 때문입니다. 2.4 GHz 대역(83.5 MHz 폭)에서는 26·40·52 MHz 어느 것도 못 피합니다. 답은 주파수 계획이 아니라 **격리**입니다(→ [캡스톤 P1](../02_캡스톤/P1_시스템설계.md)).

## B.8 안테나와 전파 — 소유 [M10](../01_모듈/M10_안테나와전파.md)

|---|---|---|

| $\eta = \dfrac{R_\text{rad}}{R_\text{rad}+R_\text{loss}}$ | 방사 효율 | |
| $G\,[\mathrm{dBi}] = G\,[\mathrm{dBd}] + 2.15$ | 기준 변환 | dBd는 **반파 다이폴** 기준 |

| $P_\text{끊김} = 1-\exp(-10^{-M/10})$ | 레일리 페이딩 | M은 페이드 마진 [dB] |

| $\mathrm{IRR} \ge D + M$ | 필요한 IRR | D는 간섭이 신호보다 센 정도 |
| $\mathrm{SNR} = 6.02N + 1.76$ | 이상적 N비트 ADC | **이상적**. 실제는 ENOB로 |
| $\mathrm{SNR}_\text{jitter} = -20\log_{10}(2\pi f_\text{in}\sigma_t)$ | 지터가 정하는 한계 | 고주파일수록 치명적 |
| $\mathrm{NSD} = -\mathrm{SNR} - 10\log_{10}(f_s/2)$ | 잡음 밀도 [dBFS/Hz] | **ENOB보다 쓸모 있다** |
| 존 $= \lfloor f/(f_s/2)\rfloor + 1$ | 나이퀴스트 존 | 짝수 존은 **스펙트럼이 뒤집힌다** |
| $f_\text{alias} = \lvert f - f_s\cdot\mathrm{round}(f/f_s)\rvert$ | 앨리어스 주파수 | |

### I/Q 불균형 → IRR

| 진폭 오차 | 위상 오차 | IRR |
|---|---|---|
| 0.5 dB | 2.0° | **29.5 dB** |
| 0.2 dB | 1.0° | 36.8 dB |
| 0.1 dB | 0.5° | **42.8 dB** |
| 0.05 dB | 0.25° | 48.8 dB |

> 📌 **45 dB 이상은 아날로그만으로 어렵습니다.** 디지털 보정이 필요합니다.

## B.10 시스템 예산 — 소유 [M12](../01_모듈/M12_시스템예산설계.md)

| 공식 | 뜻 | 주의 |
|---|---|---|
| $F_\text{total} = F_1 + \dfrac{F_2-1}{G_1} + \dfrac{F_3-1}{G_1G_2}+\cdots$ | Friis (캐스케이드 NF) | **F와 G는 선형.** dB로 넣으면 틀린다 |
| $\dfrac{1}{\mathrm{IIP3}_\text{tot}} = \dfrac{1}{\mathrm{IIP3}_1}+\dfrac{G_1}{\mathrm{IIP3}_2}+\dfrac{G_1G_2}{\mathrm{IIP3}_3}+\cdots$ | 캐스케이드 IIP3 | 역시 **선형** |
| $\text{감도} = -174 + 10\log_{10}B + NF + \mathrm{SNR}_\text{req}$ | 감도 [dBm] | 이 식은 **dB로** |
| $\mathrm{SFDR} = \tfrac23(\mathrm{IIP3}-N)$ | 스퍼 없는 동적범위 | N은 잡음바닥 [dBm] |
| $P_\text{in} = \dfrac{N + 2\,\mathrm{IIP3}}{3}$ | SFDR 상단의 입력 | |
| $\mathrm{RSS} = \sqrt{\sum\sigma_i^2}$ | 제곱합 합성 | 오차가 **독립**일 때만 |

> ⚠️ **Friis와 캐스케이드 IIP3는 선형값으로 계산합니다.** dB를 그대로 넣는 것이 이 커리큘럼에서 가장 자주 나오는 실수입니다.

> 📌 **두 법칙은 반대로 당깁니다.** 앞단 이득을 키우면 잡음지수는 좋아지고 IIP3는 나빠집니다. **한 이득 배분으로 둘 다 안 되면 AGC로 모드를 나눕니다**(→ [M12 §4](../01_모듈/M12_시스템예산설계.md) · [M11 §8](../01_모듈/M11_트랜시버아키텍처.md)).

### 역방향 설계

| 구하려는 것 | 식 |
|---|---|
| 허용 잡음지수 | $NF = \text{감도} - (-174 + 10\log_{10}B + \mathrm{SNR}_\text{req})$ |
| 요구 IIP3 | $\mathrm{IIP3} = \dfrac{3P_\text{간섭} - N}{2}$ |

## B.11 변조와 신호품질 — 소유 [M13](../01_모듈/M13_변조와신호품질.md)

| 공식 | 뜻 | 주의 |
|---|---|---|
| $\mathrm{EVM} = \sqrt{\dfrac{\overline{\lvert\text{오차}\rvert^2}}{\overline{\lvert\text{기준}\rvert^2}}}$ | 오차 벡터 크기 | 기준을 무엇으로 잡는지 규격마다 다르다 |
| $\mathrm{SNR}\,[\mathrm{dB}] = -\mathrm{EVM}\,[\mathrm{dB}]$ | EVM ↔ SNR | **변조 차수와 무관** |
| $\mathrm{EVM}_\text{tot}^2 \approx \mathrm{EVM}_1^2 + \mathrm{EVM}_2^2 + \cdots$ | 열화 요인 합성 | 독립일 때 |
| $\dfrac{1}{\mathrm{SNR}_\text{tot}} = \dfrac{1}{\mathrm{SNR}_\text{TX}}+\dfrac{1}{\mathrm{SNR}_\text{RX}}$ | 송수신 합성 | **선형값으로** |
| $\mathrm{BW}_\text{점유} = (1+\alpha)R_s$ | 상승코사인 점유 대역폭 | α는 롤오프 |
| $\mathrm{PAPR} = 10\log_{10}\dfrac{P_\text{peak}}{P_\text{avg}}$ | 첨두대평균 | OFDM은 CCDF로 본다 |

### EVM ↔ SNR

| EVM | SNR |
|---|---|
| 1 % | 40.0 dB |
| 2 % | 34.0 dB |
| **3 %** | **30.5 dB** |
| 5 % | 26.0 dB |
| 8 % | 21.9 dB |
| 12.5 % | 18.1 dB |

> ⚠️ **EVM은 제곱합으로 합쳐집니다.** 두 요인이 각각 2.19 %와 2.05 %면 합은 3.0 %이지, 4.24 %가 아닙니다.

## B.16 자주 틀리는 곳 — 열 가지

| # | 실수 | 바로잡기 |
|---|---|---|
| 1 | **Friis에 dB를 그대로 넣음** | F와 G는 **선형**으로 |
| 2 | **10log와 20log를 섞음** | 전력 10, 진폭 20 |
| 3 | **FSPL 상수의 단위** | 32.44는 **km·MHz 전용** |
| 4 | ω 대신 f를 씀 | $X_L = 2\pi f L$ |
| 5 | 위상을 도(°)로 넣음 | 삼각함수와 군지연은 **rad** |
| 6 | 시간영역에서 **왕복을 안 나눔** | 거리는 $c\Delta t/2$ |
| 7 | 반사손실 부호 규약 | 문서마다 다르다. **밝혀 적을 것** |
| 8 | **Typ을 예산에 넣음** | Typ은 보증이 아니다 |
| 9 | 데이터시트 **효율을 백오프 상태에 적용** | 동작점의 값을 봐야 한다 |

## B.S 검산 안내

> 📌 **이 문서의 모든 공식은 `scripts/check_cheatsheet.py` 에서 수치로 확인했습니다** (164항목).
>
> 공식만이 아니라 **표에 인쇄된 숫자까지** 전부 다시 계산합니다. 공식이 맞아도 표로 옮기며 틀리기 때문입니다.
>
> 확인 방식은 §B.0에 적었습니다. 특히 다음은 **독립적인 두 방법으로** 대조했습니다.
>
> | 항목 | 두 방법 |
> |---|---|
> | 자유공간 손실 | SI 형태 vs 32.44 실용형 |
> | Y 계수 잡음지수 | 잡음인자 경로 vs 잡음온도 경로 |
> | 안정도 K | 손계산 vs `scikit-rf` |
> | L형 정합 | 공식 vs 소자를 조립한 결과 vs `scikit-rf` |
> | Γ ↔ VSWR ↔ RL | 왕복 변환 |
> | 1-포트 오차 모델 | 정변환 → 역변환 왕복 |
>
> **검산에서 실제로 잡힌 것**: 자유공간 손실식에서 m와 km를 섞어 60 dB가 어긋났고, 12비트 ADC의 SNR을 73.96으로 잘못 적었으며(정답 74.00), 이미지 억압비 예제의 값을 29.5가 아닌 32로 적었습니다. 표 검산에서는 IRR 표의 36.7 dB 가 **36.8** 이어야 함도 잡혔습니다. **넷 다 이 문서에 실릴 뻔했습니다.**

> ⚠️ **경험칙은 경험칙입니다.** "IIP3 ≈ P1dB + 9~10 dB", "SRF는 동작 주파수의 3배 이상", "비아는 λ/20" — 전부 관행이고 부품·조건에 따라 다릅니다. **설계 판단의 출발점이지 근거가 아닙니다.**
