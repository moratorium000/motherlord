## 3. 책등 두께 계산 — 확인 부탁드립니다

책등은 아래처럼 계산했습니다. **종이 부피(bulk)는 제지사·롯트마다 다르므로,
귀사 기준으로 다시 계산해 주시고 값이 다르면 알려 주십시오.** 표지 전개도를
그 값으로 다시 뽑아 보내겠습니다.

| 구성 | 계산 | 두께 |
|---|---|---|
| 본문 | 280장 × 0.100 mm (80 g/m² × 부피 1.25) | 28.00 mm |
| 면지 | 2장 × 0.144 mm (120 g/m² × 부피 1.20) | 0.29 mm |
| 표지 | 2장 × 0.200 mm (250 g/m² × 부피 0.80) | 0.40 mm |
| | **합계** | **28.69 mm → 28.7 mm** |

책등이 ±1 mm 어긋나면 표1의 제목이 책등으로 말려 들어가거나 표4가 앞으로
넘어옵니다. 표지 디자인은 책등 양옆으로 **20 mm 안쪽까지 글자가 없도록**
비워 두었으므로 그 범위의 오차는 흡수됩니다.

## 4. 본문 조판

| 항목 | 값 |
|---|---|
| 판면 | A4 210 × 297 mm |
| 기본 여백 | 상하좌우 25 mm |
| **접지 여백(gutter)** | 안쪽 +5 mm → **안쪽 30 mm / 바깥 20 mm** |
| 쪽번호 | 아래 가운데, 모든 쪽 |
| 본문 글꼴 | 나눔고딕 |
| 도련 | **없음.** 재단선까지 닿는 요소가 없습니다 |

접지 여백은 홀수 쪽(오른쪽 면)은 오른쪽으로, 짝수 쪽(왼쪽 면)은 왼쪽으로
내용을 5 mm 밀어 넣는 방식으로 반영했습니다. 판면 크기는 A4 그대로입니다.

### 쪽 구성

| 쪽 | 내용 |
|---|---|
| 1 | 표제지 |
| 2–9 | 목차 (449항목) |
| 10 | 일러두기 |
| 11–556 | 본문 — Part 0 ~ Part VI, 부록 A–E, 별첨 설계서 |
| 557–559 | 백면 |
| **560** | **판권지** |

> 판권지의 **지은이 · 펴낸곳 · ISBN 칸은 비워 두었습니다.** 값이 정해지면

> 다시 뽑습니다. ISBN 바코드는 표4의 흰 상자(40 × 22 mm) 자리에 얹으면
> 됩니다.

## 5. 표지

전개도는 **왼쪽부터 표4(뒤표지) → 책등 → 표1(앞표지)** 순입니다.

```
│◀ 도련 3 ▶│◀──── 표4 210 ────▶│◀ 책등 28.7 ▶│◀──── 표1 210 ────▶│◀ 도련 3 ▶│
└──────────────────────── 재단 448.7 mm ────────────────────────┘
```

| 항목 | 값 |
|---|---|
| 인쇄 | 4도(CMYK) 단면 |
| 바탕색 | 짙은 남색 C95 M72 Y35 K40 |
| 강조색 | 금색 C5 M25 Y88 K0 · 청록 C58 M6 Y22 K0 |
| 총 잉크량 | 최대 **283 %** — 책등 남색 C98 M80 Y45 K60 (300 % 이내) |
| 후가공 | 무광 라미네이팅 |
| 표2·표3 | 인쇄 없음(백면) |

**색은 처음부터 CMYK 로 지정했습니다.** RGB→CMYK 자동 변환을 하지 마십시오.

앞표지의 원형 도형은 스미스 차트로, 이미지가 아니라 **PDF 벡터 선**입니다.
확대·축소해도 깨지지 않습니다. 도형의 가장 가는 선은 0.30 pt, 재단선은
0.25 pt 로 인쇄 한계(보통 0.25 pt) 이상입니다. 재단선만 레지스트레이션
색(4색 100 %)이며 이는 의도한 것입니다.

잉크량과 선 굵기는 `scripts/print/gen_cover.py` 가 표지를 만들 때마다
계산해서 출력하고, 300 % 를 넘거나 0.25 pt 아래로 내려가면 생성을
중단하도록 해 두었습니다.

## 6. 진행 전 확인 사항

1. **책등 28.7 mm** 가 귀사 종이 기준과 맞는지 (§3)
2. 무광 라미네이팅 두께를 책등에 더해야 하는지
3. 560쪽 무선제본이 가능한 두께인지 — 28.7 mm 는 일반적으로 가능한 범위이나,
   **초과 시 상·하권 분책**(Part 0–IV / Part V–VI+부록, 약 280쪽씩)으로
   나눌 수 있습니다
4. 본문 80 g/m² 에서 뒷비침이 문제되면 **90~100 g/m² 로 상향**을 검토
   (책등이 각각 약 32 mm / 36 mm 로 늘어납니다)
5. 부수와 납기

## 7. 다시 뽑는 법

쪽수나 종이가 바뀌면 아래를 순서대로 돌립니다. 책등 두께는 세 곳(발주서·표지·
본문)이 같은 계산을 쓰므로 따로 고칠 곳이 없습니다.

```bash
python3 scripts/docx/build.py        # 교재 재빌드 (쪽수가 바뀔 수 있음)
soffice --headless --convert-to pdf --outdir _build "_build/RF_시스템_엔지니어링_교재.docx"
cp "_build/RF_시스템_엔지니어링_교재.pdf" .

python3 scripts/print/spec.py        # 규격 계산 + 검산 6항목
python3 scripts/print/gen_cover.py   # 04_인쇄/표지_전개도.pdf
python3 scripts/print/make_body.py   # 04_인쇄/본문_인쇄용.pdf + 검산 5항목
```

종이를 바꾸려면 `scripts/print/spec.py` 위쪽의 `BODY_PAPER` · `COVER_PAPER` ·
`END_PAPER` 를 고칩니다. 부피(bulk) 값만 바꿔도 책등과 표지 전개도가 함께
따라옵니다.
